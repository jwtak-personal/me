# 나 관리

돈, 차, 건강, 피부처럼 주기적으로 챙길 일을 한 화면에서 보는 개인용 웹앱. 폰 홈 화면에 추가해 앱처럼 쓴다.

- 빌드 없음. `index.html`, `styles.css`, `js/` 가 전부다
- 기록은 기기 안(localStorage)에 저장하고, 설정에서 비공개 저장소를 연결하면 그 저장소의 `data.json` 과 맞춘다
- 이 저장소에는 개인 기록을 넣지 않는다. 기본 항목(`js/templates.js`)은 일반적인 주기만 둔다

```
python -m http.server 5190   # 로컬에서 열기
node --test                  # 주기 계산과 병합 테스트
```
